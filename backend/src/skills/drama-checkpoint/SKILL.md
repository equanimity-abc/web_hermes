# drama-checkpoint

渲染与导出前的强制检查点。**只提醒、只建议，不做破坏性动作。**

## 渲前检查点

1. 分镜已 `classify_shots`（定场 L0、对白 L1、锁 kind 不覆盖）。
2. 看 `budget` 是否超支；超支先提醒人调高预算，不要硬渲贵模型。
3. 有对白镜未锁 `scene` 时，提醒人先锁画面再开口型。

## 导出前检查点

1. 先 `qc_episode`；`skipped` 不得记为通过。
2. 响度不达标只 `remix` 重混，不重渲各镜 clip。
3. BGM 无 license 禁止导出。

## 失败后续跑

- 用户说「继续 / 重试 / 接着渲」→ `tiktok_drama action=resume_produce slug=… episode=…`（可带上次 `job_id`）。
- 系统会**先复检上次失败点是否已被人工修好**（如改定妆、锁新画面）；已解决则向后推进，未解决则基于当前锁态/资产继续。
- 收窄脏层，跳过已通过镜，从当前未解决步骤跑到导出。
- **禁止候选项墙与自动重抽**：不得 `generate_candidates` / `choose_candidate`。

## 身份失败半自动

- `qc_shot` 身份失败会**自动标脏** scene/motion/clip（不重配音）。
- **若 `scene` 已锁定且图在**：不得标脏 scene、不得重绘；续跑只复检身份。要换图须人先解锁。
- 续跑时会 live 复检身份：人工改定妆后若已过，则自动继续运动/口型/导出。
- 但**入队重渲必须人在工作台点**；你不自动通过、不自动烧贵模型。

## 不要做

- 不要整集盲渲（除非用户明确要求 force）。
- 不要替人点验收「通过」。
- 不要改 `agent/loop.py`。
