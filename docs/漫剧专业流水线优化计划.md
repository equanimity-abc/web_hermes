# AI 漫剧专业级制作流水线 · 优化计划

> 目标：把现有「可改、可锁、可单镜重渲」的草稿流水线，升级为一条**每个节点都可人工干预、每个节点都可单独配置模型、默认推荐 + 人工覆盖**的专业顶级漫剧生产线。

---

## 1. 现状全盘分析

### 1.1 已具备的资产（盘点结果）

| 能力 | 现状 | 模块 |
|------|------|------|
| 通用 Agent 腰 | 会话/流式/审批/记忆/沙箱/工具循环 | agent/、stream_manager、tools/ |
| 剧情结构 | 立项→Bible→大纲→分集→分镜 Markdown | tiktok_drama 插件 |
| 分镜资产化 | shots.json + 每镜 scene/overlay/voice/clip | drama_shots、drama_video |
| 镜头级重渲 + 分层锁 + 脏层 | scene/overlay/voice/clip/assemble | drama_shots、drama_studio |
| 角色一致性 | 角色卡 + 参考图 + 音色绑定 | drama_characters |
| 候选墙 | 每镜 2–4 候选、点选锁定、手传覆盖 | drama_video、drama_studio |
| 时间线 | 镜序/切点/转场/音量，不毁源 clip | drama_timeline、drama_video |
| 音频总线 | BGM/SFX 分轨 + duck + -14 LUFS | drama_audio |
| 后台渲染队列 | 进度/取消/重试，不阻塞聊天 | drama_queue |
| 镜头分类 + 模型路由 | kind/size/speaker + models.json | drama_models |
| 质量阶梯 | L0 静图运镜 ~ L4 稀疏关键帧 | drama_i2v、drama_keys |
| 口型 | 仅 dialogue 特写，失败回退闭口 | drama_lip、drama_lse |
| QC/验收 | identity、口型、响度、闪烁 | drama_qc |
| 工作台 UI | 分镜/剧本/角色/时间线/任务条/验收 | frontend/drama |

### 1.2 离「专业顶级」的差距

| 维度 | 现状 | 差距 |
|------|------|------|
| **配置体系** | 只有零散 env + 每项目 models.json，无统一预设中心 | 缺「一键预设 + 逐节点覆盖」 |
| **模型适配** | 硬编码几种 provider，扩模型要改代码 | 缺「插件化 provider 适配器」 |
| **生成鲁棒性** | TTS/出图失败静默降级，不重试不告警 | 缺「重试/熔断/降级清单」 |
| **角色一致性** | 参考图只写进 prompt，弱保证 | 缺「参考图引导 + 硬指标闸门」 |
| **人工效率** | 逐镜点、改坏回不去 | 缺「批量操作 + 版本回滚」 |
| **成本治理** | 无成本预估/账单 | 缺「cost per shot + 预算闸」 |

## 2. 目标与核心原则

### 2.1 什么算「专业顶级」

- **流程清晰**：14 个节点，每个节点的输入、产出、锁语义、可改项都明确。
- **处处可干预**：任一节点产出后，人都能改、能锁、能单点重做下游。
- **处处可配置**：任一节点用什么模型/provider，都能在界面改，不改代码。
- **默认可用 + 可进阶**：默认给一套「够用且便宜」的推荐，也能一键切「顶级贵模型」。
- **可量化验收**：除人工看，还有客观分数（identity / 口型 / 响度 / 闪烁）。

### 2.2 五条设计原则

1. **人 是 导演，Agent 是摄制组** —— 每一步默认可改、可锁、可只重做下游。
2. **资产 + 锁 + 脏** —— 粒度到镜头，成片是镜头资产拼出来的。
3. **配置三层覆盖** —— 全局预设 → 系列/项目 → 分集/单镜，越往下优先。
4. **模型走适配器** —— provider 插件化，路由按节点读配置，不硬编码。
5. **金钱按镜头花** —— 贵模型只在「该用的镜头」上用，其余走便宜档。

## 3. 统一配置与模型路由体系（本计划的核心）

### 3.1 三层配置优先级（从低到高）

```
① 全局默认预设（backend/data/presets/*.json，含 pro / balanced / cheap 三档）
        ↓ 可被覆盖
② 项目级 models.json（workspace/dramas/{slug}/models.json，已存在，升级为完整 schema）
        ↓ 可被覆盖
③ 分集/单镜覆盖（分集 doc 里存 overrides，镜头检查器可改）
```

**规则**：读配置时按 ③ > ② > ① 合并；任何一层缺省就沿用上一层。

### 3.2 统一 Provider 模型 Schema（每个节点都用同一格式）

```json
{
  "preset": "pro",
  "nodes": {
    "script": {
      "provider": "deepseek",
      "model": "deepseek-v4-flash",
      "refine_model": "deepseek-reasoner"
    },
    "scene": {
      "provider": "flux",
      "model": "flux-pro",
      "kind_overrides": {
        "dialogue": { "provider": "jimeng", "model": "char-consistent", "use_ref": true },
        "action":   { "provider": "jimeng", "model": "char-consistent", "use_ref": true },
        "establishing": { "provider": "flux", "model": "flux" }
      },
      "style_pack": "guofeng"
    },
    "motion": {
      "ladder_default": { "establishing": "L0", "dialogue": "L2", "action": "L3" },
      "providers": {
        "L0": { "provider": "ffmpeg", "kind": "kenburns" },
        "L1": { "provider": "kling", "model": "i2v-2s",   "fallback": "L0" },
        "L3": { "provider": "kling", "model": "i2v-4s",   "fallback": "L1" },
        "L4": { "provider": "kling", "model": "i2v-4s",   "interp": "frame-interp", "fallback": "L3" }
      }
    },
    "lip":     { "provider": "musetalk", "only_kinds": ["dialogue"], "fallback": "closed-mouth" },
    "tts":     { "provider": "edge-tts", "voice_map": "characters", "upgrade": { "provider": "volcano", "model": "high-fidelity" } },
    "bgm":     { "provider": "library", "duck_db": -12, "catalog": "licensed" },
    "sfx":     { "provider": "library" },
    "subtitle":{ "style": "karaoke", "font": "NotoSansCJK" },
    "style":   { "pack": "guofeng" }
  }
}
```

### 3.3 三档默认预设（开箱即用）

| 预设 | 画面 | 运动 | 口型 | 配音 | 适用 |
|------|------|------|------|------|------|
| `cheap` | flux(免费) | L0 静图运镜 | 关闭 | edge-tts | 试稿/跑通 |
| `balanced`（默认） | flux + 参考图 | L1 单帧 I2V | dialogue 可开 | edge-tts | 日常量产 |
| `pro`（专业顶级） | 即梦/可灵 角色一致性 | L3/L4 真 I2V + 稀疏关键帧 | MuseTalk | 火山/微软高拟真 + 角色克隆 | 精品/商用 |

### 3.4 每个节点都可人工修改

工作台增加「**节点配置面板**」：选中任一节点，即可改 provider/model/参数，改动**只作用于该节点与该层作用域**（全局/项目/分集/单镜），立即持久化，不要求重启。

## 4. 完整流水线（14 个节点）

> 每个节点统一标注：**作用 / 默认推荐 / 可改配置 / 人工干预点 / 产出资产**。

### 节点 1 · 立项 Project
- **作用**：定题材、受众、logline、集数、画幅。
- **默认推荐**：Agent 用 `script` 节点模型（deepseek）。
- **可改配置**：标题/logline/定位/禁区/目标时长。
- **人工干预**：立项即锁，后续剧本大纲不推翻定位。
- **产出**：`project.json`。

### 节点 2 · 世界观 / 人设 Bible
- **作用**：角色关系、口头禅、视觉锚点、风格基调。
- **默认推荐**：`script` 模型精修。
- **可改配置**：bible 全文、风格包选择。
- **人工干预**：改人设 → 下游角色卡/剧本变脏。
- **产出**：`bible.md`。

### 节点 3 · 角色资产 Character
- **作用**：三视图、服装、配色、定妆参考图、音色。
- **默认推荐**：出图用 `scene` 的 `use_ref` 模型生成定妆图；配音绑定 `tts.voice_map`。
- **可改配置**：look/colors/catchphrase/voice，参考图锁定。
- **人工干预**：上传/重抽/锁定定妆图（全片一致性根基）。
- **产出**：`characters.json` + `characters/{id}.png`。

### 节点 4 · 系列大纲 Outline
- **作用**：每集钩子/反转/悬念、节奏。
- **默认推荐**：`script` 模型。
- **可改配置**：调集顺序、改集摘要。
- **人工干预**：改大纲只脏未锁的集。
- **产出**：`outline.md`。

### 节点 5 · 分集剧本 Script
- **作用**：对白、时长、分镜指令。
- **默认推荐**：草稿 `deepseek-flash` → 精修 `deepseek-reasoner`。
- **可改配置**：改词/加删场/标角色。
- **人工干预**：改剧本 → 预览影响哪些 Shot → 确认才同步。
- **产出**：`episodes/epNN.md`。

### 节点 6 · 分镜表 Shot List
- **作用**：每镜 kind/size/speaker/画面/运镜/时长。
- **默认推荐**：Agent 建议分类，人可 Lock。
- **可改配置**：kind/size/speaker/camera/duration。
- **人工干预**：拆镜/调序/锁定 kind。
- **产出**：`shots.json`。

### 节点 7 · 关键帧 / 画面 Scene
- **作用**：每镜出图，可多候选。
- **默认推荐**：`scene` 节点表；对话/动作走 `use_ref` 一致性模型，定场走便宜 flux。
- **可改配置**：provider/model/prompt/seed/风格。
- **人工干预**：候选墙重抽 4 张、点选锁图、手传覆盖。
- **产出**：`shotNN_scene.png` + `candidates/`。

### 节点 8 · 镜头运动 Motion
- **作用**：推拉摇、I2V、稀疏关键帧，按 kind 走 L0–L4。
- **默认推荐**：`motion` 节点表；action 走真 I2V，定场禁止贵模型。
- **可改配置**：每档 ladder 的 provider/model/fallback。
- **人工干预**：钉 3–5 关键帧、锁姿态、失败回退静图。
- **产出**：`shotNN_motion.mp4`。

### 节点 9 · 口型 Lip
- **作用**：仅 dialogue CU/MCU 开口型。
- **默认推荐**：MuseTalk（本地）/云端口型；失败回退闭口。
- **可改配置**：provider/only_kinds/阈值。
- **人工干预**：标 speaker、跳过不适格镜头。
- **产出**：`shotNN_lip.mp4`。

### 节点 10 · 配音 TTS
- **作用**：按角色音色合成对白。
- **默认推荐**：edge-tts 免费；专业档切火山/微软高拟真或 GPT-SoVITS 克隆。
- **可改配置**：voice、语速、情绪、音量、起止。
- **人工干预**：逐句重配、锁音。
- **产出**：`shotNN.mp3`。

### 节点 11 · 字幕 Subtitle
- **作用**：烧字幕，可卡拉OK。
- **默认推荐**：本地渲染（PIL/ASS），可切卡拉OK。
- **可改配置**：位置/字号/字体/颜色/逐字。
- **人工干预**：改字、改时间。
- **产出**：`shotNN_overlay.png`。

### 节点 12 · BGM / 音效 Audio
- **作用**：整集 BGM + 镜头音效，duck 人声。
- **默认推荐**：授权曲库；duck -12dB，导出 -14 LUFS。
- **可改配置**：换轨/音量/duck/淡入淡出/license。
- **人工干预**：时间线上打 BGM 轨与音效点。
- **产出**：`ep_bgm.wav` + `mix/epNN_mix.json`。

### 节点 13 · 时间线成片 Timeline / Assemble
- **作用**：按时间线拼接 + 转场 + 混音导出。
- **默认推荐**：ffmpeg。
- **可改配置**：镜序/切点/转场/音量，导出不毁源 clip。
- **人工干预**：时间线拖拽，预览后导出。
- **产出**：`epNN.mp4`。

### 节点 14 · 验收 QC / Accept
- **作用**：列脏镜/失败项，客观分数 + 人工通过。
- **默认推荐**：`drama_qc` 跑 identity/口型/响度/闪烁。
- **可改配置**：各指标阈值。
- **人工干预**：通过 / 退回某 Shot。
- **产出**：验收结论 + qc 分数。

## 5. 分阶段实施计划（R0–R8）

> 在现有 Q0–Q8 基础上做「专业化」改造，不改 `agent/loop.py`。

| 代号 | 做什么 | 验收 | 状态 |
|------|--------|------|------|
| **R0** | 统一配置中心：`presets/*.json` 三档 + 三层合并读取 + models.json 升级为新 schema + 发布 `get_node_config / put_node_config` API | 同一项目能一键切 cheap/balanced/pro，节点配置落盘并生效 | 建议 |
| **R1** | Provider 适配器插件化：`providers/` 目录，统一 `generate_image / i2v / lip / tts` 接口，动态加载 | 加一个新模型只需写适配器，不改业务代码 | 建议 |
| **R2** | 节点配置面板：工作台检查器加「模型/参数」区，全局/项目/分集/单镜四层切换 | 不改代码即可给每镜换 provider/model | 建议 |
| **R3** | 鲁棒性：出图/TTS/I2V/口型统一重试 + 熔断 + 失败降级清单 | 一集渲完返回「降级/失败项」，无静默默片 | 建议 |
| **R4** | 角色一致性硬闸：参考图引导(IP-Adapter若可)、identity 余弦阈值、不合格标脏可重抽 | 同角色连续 5 镜 identity 达标 | 建议 |
| **R5** | 批量操作：分镜多选 + 批量改运镜/音色/kind/i2v | 一集 8 镜改参数从几十次点击降到几次 | 建议 |
| **R6** | 版本回滚：scene/shots.json 自动快照 + 撤销 | 改坏一键回退上一版 | 建议 |
| **R7** | 成本治理：每 provider 带 `cost_per_shot`，渲染前预估 + 按钮旁显示 + 预算闸 | 开工前看见账单，贵模型按镜花 | 建议 |
| **R8** | 验收清单页：汇总 fallback/无声/未锁/未过 identity，一键退回 | 一集能不能过，一屏看清 | 建议 |

**顺序**：R0 → R1 → R2（配置地基）→ R3（稳定性）→ R4（一致性）→ 其余可并行。

---

## 6. 验收标准 / 成功指标

1. **不开代码**，就能给任意节点换模型（R0–R2 完成后）。
2. **一集渲染**必有「成功/失败/降级」完整清单，无静默默片（R3）。
3. **同角色连续 5 镜** identity 达标且可自动重抽（R4）。
4. **一集 8 镜**的批量改参数 ≤ 5 次操作（R5）。
5. 上架级作品：定妆锁脸 + 特写开口 + 动作短 I2V + 音乐情绪 + 导演锁资产。
