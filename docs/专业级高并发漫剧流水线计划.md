# 专业级 AI 漫剧制作流水线 · 高性能高并发计划（质量优先版）

> **设计立场**：先以**最高质量 / 专业成片**为硬目标建设流水线；**暂不考虑经济效益**。降级、便宜档、免费后端作为后续独立章节（本文仅预留挂钩，不展开实现）。  
> **基线**：现有 6 阶段工作台 + `produce_episode` HQ + L0–L4 阶梯 + Ark 默认预设。本文在其之上定义「专业级目标态」。

---

## 0. 一句话目标

把当前「可跑通、可干预、默认可降级」的草稿生产线，升级为：

**导演可控 · 镜头资产化 · DAG 并行 · 失败即止（Fail Loud）· 客观 QC 硬闸 · 可横向扩展的专业级摄制流水线。**

成片标准对齐短剧/漫剧交付：角色一致、动作可信、口型同步、响度合规、时间线可剪、可批量重渲且不毁源。

## 1. 专业级质量契约（Quality Contract）

### 1.1 成片硬门槛（全部必须满足才允许 Export）

| 维度 | 硬门槛 | 不达标动作 |
|------|--------|------------|
| **角色身份** | 对白/反应/动作镜 identity ≥ 0.75（相对锁定定妆图） | 自动重试出图 ≤2；仍失败 → 镜标 `qc_failed`，阻断 assemble |
| **运动** | dialogue/reaction 最低 **L1 真 I2V**；action 最低 **L3 真 I2V**；具备 ≥3 key 时升 **L4** | **禁止**静默 Ken Burns / mock 冒充真 I2V；必须写 `degraded=true` 且默认阻断 HQ 导出 |
| **口型** | dialogue 且景别 ∈ {CU,MCU,ECU}：真 lip provider 成功 + LSE 达阈 | mock lip **不算过闸** |
| **闪烁** | 相邻帧 SSIM ≥ 0.85（运动/口型段） | 重渲 motion/lip |
| **响度** | 整集 −16…−12 LUFS，目标 −14；真峰 ≤ −1 dBTP | remix 后重测 |
| **字幕** | 可读、不挡脸关键区；专业档启用逐字/半句卡点（karaoke ASS） | 静态烧录仅作开发预览 |
| **版权** | BGM/SFX 有 license 记录 | 无 license 禁止 export |

### 1.2 「禁止静默降级」原则（质量优先期）

1. Provider 不可用 → **任务失败 + 明确错误**，不偷偷换成 flux/edge-tts/mock。  
2. `status=skipped` / 缺依赖 **永不计为 pass**（已有契约，需贯彻到 HQ produce）。  
3. 工作台允许人工强制「带瑕疵导出」；**Agent 一键成片默认不允许**。  
4. 后续降级方案通过独立 `quality_profile: studio | draft` 切换，不污染 `studio` 路径。

### 1.3 专业档默认模型（已与产品对齐，可再抬）

| 节点 | 默认（质量优先） | 备选（同档可换） |
|------|------------------|------------------|
| 剧本/分镜 | Ark Seed Character / GLM-5.2 | DeepSeek v4-pro、Kimi k3 |
| 定妆/分镜图 | Seedream 5.0 Pro | Kling Omni、Qwen-Image |
| 图生视频 | Seedance 2.5 | Kling Video、万相 I2V |
| 配音 | Seed Audio | CosyVoice 高拟真 |
| 口型 | PixVerse → LatentSync | MuseTalk（仅降档时） |

运动阶梯目标态：**L0 仅用于定场/插入/群像/标题**；叙事主体镜不以 L0 交差。

## 2. 目标架构：镜头级 DAG + 阶段屏障

### 2.1 流水线拓扑（逻辑）

```
Premise
  → Script/Bible/Outline（LLM，可并行多草案）
  → Shot Graph（shots.json）
  → Cast Farm（角色卡 + 定妆，角色间并行）
  → [Barrier: 全角色 ref_locked]
  → Scene Farm（分镜出图 N 候选并行）
  → [Barrier: scene_locked 或 auto-pick + identity gate]
  → Motion Farm（I2V / Keys，镜间并行）
  → Voice Farm（TTS，镜间并行）
  → Lip Farm（仅合格 dialogue，镜间并行）
  → Per-shot Clip Assemble（本地 CPU，高并行）
  → [Barrier: per-shot QC bundle pass]
  → Episode Timeline + BGM/SFX Mix
  → [Barrier: episode loudness + checklist]
  → Export (epNN.mp4)
```

要点：

- **跨镜并行**，**跨阶段有屏障**（依赖角色一致性与 QC）。  
- 单镜内部仍是：`scene → overlay → voice → lip → clip`，但多镜之间不再串行。  
- Agent `produce_episode` 与工作台共享同一 Job Graph，禁止再走「同步串行 for 循环」。

### 2.2 与现状差距（必须消灭）

| 现状 | 专业目标态 |
|------|------------|
| HQ produce 镜间 **串行** | 镜间 **并行池**（默认 8–16，可配） |
| Agent 路径强制 sync、阻塞对话 | **异步 Job + SSE/轮询**；对话只收进度事件 |
| 失败静默 mock | Fail Loud + 可恢复重试 |
| 候选墙 HQ 强制 1 张 | HQ 默认 **4 候选并行**，identity 自动选优 |
| Queue 进程内线程 + JSON | 可演进为 Redis/DB 队列；先强化现有队列契约 |

## 3. 高并发与高性能设计

### 3.1 并发分层

| 层 | 单位 | 建议默认 | 说明 |
|----|------|----------|------|
| **Cluster workers** | 进程/机器 | ≥ CPU 核数或独立渲染机 | 跑 ffmpeg / 本地后处理 |
| **Episode jobs** | 一集一条 exclusive | 同 slug:ep 互斥 | 防 shots.json 写穿 |
| **Shot tasks** | 一镜一任务 | `SHOT_CONCURRENCY=8~16` | 受 provider RPM 限制 |
| **Intra-shot candidates** | 一镜子任务 | 4 | 出图候选并行 |
| **Provider lanes** | 按厂商令牌桶 | Ark / DashScope / Lip 分轨 | 避免打爆单一 API |

### 3.2 调度器（Professional Scheduler）

在现有 `drama_queue` 上升级为 **DAG Scheduler**：

1. **任务类型**：`script` / `cast_ref` / `scene_cand` / `i2v` / `tts` / `lip` / `clip` / `qc` / `assemble` / `export`  
2. **依赖边**：显式 `depends_on[]`，屏障节点 `barrier_cast` / `barrier_scene` / `barrier_shot_qc`  
3. **优先级**：人工「只重渲本镜」> 批量补洞 > 全量 HQ  
4. **幂等键**：`(slug, ep, shot, layer, model_fingerprint, prompt_hash)`  
5. **取消语义**：取消父 Job → 级联取消子 Task；已落盘资产保留  
6. **背压**：按 provider lane 排队；本地 CPU 任务与远端 API 任务分池，避免互相饿死  

### 3.3 性能关键路径优化

| 热点 | 策略 |
|------|------|
| LLM 剧本 | 大纲与分集可并行；长文流式落盘；失败换备选 LLM 不换质量档 |
| 出图 | 批量提交 + 异步轮询；本地只做下载/归一化/裁切 |
| I2V | 长轮询合并；同一 provider 连接复用；超时阶梯重试 |
| TTS | 按角色批请求；缓存 `(voice, text_hash)` |
| Lip | 仅 CU/MCU；预裁脸 ROI，减少上传体积 |
| FFmpeg | 预置滤镜图；NVENC/QSV 可选；assemble 用 concat demuxer 避免二次编码（质量优先时可选 CRF 重编） |
| 存储 | 镜头资产本地 SSD；导出可异步上传对象存储（后续） |

### 3.4 可观测性（专业生产线必备）

每 Job/Task 记录：

- 阶段耗时瀑布（script / cast / scene / i2v / voice / lip / assemble）  
- Provider 调用次数、失败率、p50/p95 等待  
- QC 分数分布  
- 每镜成本占位字段（**先记账，不闸预算**——为后续降级准备）

UI：任务条展示「第 k/n 镜 · 当前层 · ETA」。

## 4. 分阶段专业能力规格

### 4.1 Script（编剧室）

- 强制输出：系列 bible、集大纲、本集 Markdown、shot 列表、时长约束（默认 1×60s 可配）。  
- 多草案：并行 2 路 LLM → 导演选定或自动评分（结构完整性 / 钩子密度）。  
- 分镜解析严格：禁止把多集 dump 进单集；episode 边界硬校验（已部分具备，需作为硬闸）。

### 4.2 Cast（造型）

- 全角色并行定妆；每角 **4 候选**；自动 identity 自洽（同角多候选互比）。  
- 定妆锁定后写入 **character embedding**（ArcFace），供后续出图硬闸。  
- 物品/场景资产同样走 Seedream，纳入引用图集合。

### 4.3 Scene（摄影）

- 路由按 kind；对白/动作 **强制 use_ref**。  
- HQ：4 候选 → identity 排序 → 自动锁最优（可人工改选）。  
- Prompt 编译：角色 look + 色板 + 镜头 size + 光影一致性 token。

### 4.4 Motion（摄影指导 / 动捕替代）

| Kind | 专业最低档 |
|------|------------|
| establishing / insert / crowd / title | L0 可接受 |
| reaction | **L1 真 I2V** |
| dialogue | **L1 真 I2V** + 后续 lip（L2 语义） |
| action | **L3**；keys≥3 → **L4** |

- L5（全帧插值/动画中间帧）列入 **Phase E 研究项**，不阻塞专业交付。  
- 多角色动作：Phase D（先支持双人 CU 切换，再群戏）。

### 4.5 Voice + Lip

- TTS：角色音色绑定；对白轨与旁白轨分离（已有 dialogue track 方向需默认开启）。  
- Lip：仅合格景别；PixVerse/LatentSync 真链路；失败重试后仍失败 → 镜失败。  
- 禁止「远景强行对口型」。

### 4.6 Assemble（剪辑室）

- 时间线非破坏；转场可配；BGM duck；SFX 点位（后续库）。  
- 字幕：专业档 ASS 卡点。  
- Export 前跑 **episode checklist**：全部镜 `qc_passed` + loudness + license。

## 5. 实施路线图（质量优先，不含降级实现）

### Phase A — 诚实与硬闸（1–2 周）

**目标**：专业路径不再「假装成功」。

- [ ] HQ produce / Agent 路径：**禁止** mock/edge/Ken Burns 静默顶替（缺 Key 直接 fail）  
- [ ] Export 前强制 `qc_episode_checklist`；`skipped ≠ pass`  
- [ ] identity 阈值抬到专业档默认 0.75；失败阻断 assemble  
- [ ] 任务事件：每镜开始/结束/失败原因进入 SSE  

**验收**：无 Ark Key 时 HQ 明确失败；有 Key 时失败有可读错误；不再出现「假成片」。

### Phase B — 镜间并行 DAG（2–3 周）

**目标**：吞吐翻倍级提升。

- [ ] 将 `produce_episode_hq` 拆成 DAG Task；镜间并行 `SHOT_CONCURRENCY` 可配（默认 8）  
- [ ] Cast / Scene candidates / I2V / TTS / Lip 分池  
- [ ] Provider 令牌桶（Ark / DashScope / Lip 分 lane）  
- [ ] Agent produce **异步化**（返回 job_id；进度推送）  

**验收**：12 镜 × 60s 样片端到端墙钟时间 vs 串行基线 ≥ **3×** 加速（同 API 配额下）。

### Phase C — 专业运动与口型（2–4 周）

**目标**：画面「像拍的」而不是「像动图」。

- [ ] reaction/dialogue 默认真 L1；action 默认真 L3；keys 自动触发 L4  
- [ ] Seedance / Kling 失败重试策略（指数退避 + 备选同档模型，不降到 L0）  
- [ ] Lip 真链路稳定 + LSE 硬闸  
- [ ] 字幕 karaoke ASS  

**验收**：人工盲测 10 镜，动作/口型达标率 ≥ 80%；QC 自动通过率 ≥ 70%（可人工补洞）。

### Phase D — 系列一致性与剪辑室（2–3 周）

- [ ] 角色 embedding 跨集复用；色板/光影 token 系列级  
- [ ] 双人对话镜切换策略；基础 SFX  
- [ ] 版本快照：每阶段一键回滚  
- [ ] 可观测仪表（耗时瀑布、失败热力）  

### Phase E — 研究上限（并行研究，不挡交付）

- L5 全帧插值 / 动画中间帧  
- 多角色同框强一致  
- 云端对象存储 + 多机 worker  
- （此后才启动）**质量档降级矩阵** `studio → balanced → draft`

## 8. 成功标准（Definition of Done）

在配置齐备（Ark + 口型链路）的前提下：

1. **质量**：抽样 1 集 60s，硬门槛全过；无需「假成片」才能看流程。  
2. **吞吐**：同等镜头数，墙钟时间相对当前串行 HQ ≥ 3×。  
3. **可控**：任一步可锁、可单镜重做、可看失败原因。  
4. **诚实**：任何降质必须显式标记；`studio` 路径无静默 mock。  
5. **可演进**：账本字段与 profile 钩子就位，便于下一阶段做降级，而不推翻架构。
