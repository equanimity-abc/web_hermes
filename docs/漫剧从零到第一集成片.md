# 漫剧从零到第一集成片 · 操作步骤

> 本流程对应**新版「漫剧」工作台**：顶部是 6 阶段线性步进器（剧本 → 角色 → 画面 → 视频 → 声音 → 成片），一次只做一步，底部有「下一步」按钮。
> 示例统一用《重生之逆袭千金》：豪门养女被赶出家门，重生回到三年前复仇翻盘，竖屏 9:16、每集约 45 秒。

---

## 一、跑高质量的前提（环境配置）

| 档次 | 需要配置 `backend/.env` | 效果 |
|------|------------------------|------|
| 免费跑通 | `DEEPSEEK_API_KEY` | 剧本走 deepseek；出图/视频/口型走本地降级（flux / mock / edge-tts），能看流程、画质一般 |
| **高质量（推荐）** | `DEEPSEEK_API_KEY` + `DASHSCOPE_API_KEY` + `DASHSCOPE_MAAS_BASE_URL` | 出图走万相 qwen-image-plus、动作/反应走万相图生视频、配音走高拟真 cosyvoice、口型走 PixVerse 真对口型 |
| 顶格锁脸 | 上一条再配 `CONSISTENT_IMAGE_URL`（或把角色/对白镜头出图 provider 切到 `kling-image`） | 出图真正吃定妆参考图，同角色连续镜头不崩脸 |

> 新版**默认就是 `pro` 顶级配置**，工作台不再有「预设/风格/预算」切换；没配到的商用 API 会由后端诚实降级到免费档，配好即自动使用，无需手切。

---

## 二、6 阶段总览

```
① 剧本  一句话 → 完整剧本 + 分镜表（大模型生成）
② 角色  文生图自动出定妆图 → 锁图
③ 画面  逐镜文生图 → 候选墙锁图
④ 视频  图生视频（I2V 运动）
⑤ 声音  配音 + 口型
⑥ 成片  拼接 + BGM + 导出
```

前 3 步决定「画面与一致性」，第 4/5 步决定「动起来与开口说话」，第 6 步交付。

---

## 第 0 步 · 让 Agent 自检（可选）

在「聊天」页发一句：

```
请告诉我你现在能做哪些漫剧制作动作，并简述一条竖屏短剧到成片的标准流程。不要创建项目。
```

---

## 第 1 步 · 立项（聊天页，仅一次）

```
用 tiktok_drama 建一个漫剧项目，action=init：
- slug: rebirth_heiress
- title: 《重生之逆袭千金》
- logline: 被赶出家门的豪门养女，重生回到三年前复仇翻盘。
要求：竖屏 9:16，目标每集 45 秒。建好后回我项目路径和 project.json 关键内容。
```

> 建好后切到左侧「**漫剧**」工作台，点开该项目，接下来全程用工作台的 6 阶段步进器操作。

---

## 第 2 步 · 准备角色卡文本（可让 Agent 代填）

角色卡需要「名字 / 外形 / 配色 / 音色」四要素，才能自动出定妆图。两种方式任选：

**A. 让 Agent 从剧本自动建卡（推荐，快）**——在第 3 步之后发一句：

```
基于我第 1 集剧本里的出场角色，用 save_character 逐个建角色卡，每个都填好
name / look(详细外形，进 prompt) / colors / voice / aliases，不要生成图片。
建完把每个角色的 id/name/look 回我。
```

**B. 工作台手动填**——进入「② 角色」页，点「添加角色」，逐个填「名字/外形/配色」，保存卡片。

---

## 第 3 步 · ① 剧本（工作台）

1. 在步进器点「**剧本**」。
2. 在「故事梗概」输入框粘贴一句话：

```
重生复仇：被赶出家门的豪门养女回到三年前，开始逆袭复仇。
```

3. 点「**生成剧本**」——后端的 deepseek 会直接生成完整剧本与分镜表并落盘。
4. 在下方文本框检查剧本：**前 3 秒必须有钩子、每集结尾留悬念**；如需微调直接改文本。
5. 点「保存剧本」。

> 这一步已同步生成 shots.json，不再需要单独 `parse_shots` / `classify_shots`。

---

## 第 4 步 · ② 角色（文生图自动定妆）

1. 点步进器「**角色**」，确认每个角色卡的外形/配色已填好。
2. 点「**一键生成所有定妆图**」——后端按 `name + look + colors` 文生图，自动写入定妆参考图。
3. 逐张审图：**满意 → 点「锁定」**；**不满意 → 点「生成」重抽**或「手传兜底」覆盖。
4. 全部锁定后再进入下一步。

> 这是全片一致性的第二根支柱（第一根是剧本里的角色名），务必锁好再出画面。

---

## 第 5 步 · ③ 画面（逐镜出图 + 锁图）

1. 点步进器「**画面**」。
2. 点「**一键全部出图**」——每镜生成候选，自动把第 1 张作为当前画面。
3. 在候选墙**点选最满意的一张锁定**；不满意的点「重抽 4 张」。
4. 确认每个镜头都有满意画面并锁定。

> 对话框里对白/反应/动作镜头走 `use_ref` 一致性模型，会吃上一步锁定的定妆图。

---

## 第 6 步 · ④ 视频（图生视频）

1. 点步进器「**视频**」。
2. 点「**一键全部生成视频**」——对每个非定场镜头跑图生视频（I2V 运动）；定场/群像/标题强制静图运镜，避免烧钱。
3. 逐镜检查动效是否自然，单镜可重跑。

> 动作镜头走真 I2V（万相图生视频），对话镜头只做轻微 idle 运动，关键帧/稀疏关键帧仍保留为进阶能力。

---

## 第 7 步 · ⑤ 声音（配音 + 口型）

1. 点步进器「**声音**」。
2. 点「**一键生成配音与口型**」——按每个角色卡的音色合成对白，并对 dialogue/CU/MCU 特写开口型。
3. 逐镜试听对白，口型不对的单镜可重跑。

> 高质量档配音走 cosyvoice，口型走 PixVerse 真对口型；没配 API 时自动降级 edge-tts + mock 口型。

---

## 第 8 步 · ⑥ 成片（导出 + 交付）

1. 点步进器「**成片**」。
2. （可选）「上传 BGM」挂配乐。
3. 点「**导出整集**」——拼接 + 转场 + 混音 + 响度标准化。
4. 在预览区回看整集 mp4，满意即完成第一集成片。

---

## 常见补救（工作台内随时做）

| 情况 | 操作 |
|------|------|
| 某一镜画面不顺眼 | ③ 画面对该镜「重抽 4 张」再锁 |
| 某一镜动作不对 | ④ 视频对该镜「生成视频」重跑 |
| 改一句台词 | ① 剧本改文本 → 保存 → 对该镜重做声音 |
| 某角色崩脸 | ② 角色重新「生成」定妆图并锁定 |
| 换 BGM | ⑥ 成片重新「上传 BGM」→ 导出 |
| 看渲染/导出进度 | 底部「渲染任务」条 |

```

```

## 关键提醒

1. **前 3 秒钩子**决定留存，① 剧本阶段就要卡死。
2. **定妆图必须先锁定**，否则角色崩脸。
3. **默认即 pro**：商用 API 配好就自动用高档（万相出图/图生视频、cosyvoice 配音、PixVerse 口型），没配就诚实降级，不必再切预设。
4. **口型现状**：dialogue/CU/MCU 走 PixVerse 真对口型（需 `DASHSCOPE_MAAS_BASE_URL`）；否则 mock 波形动效。
5. 先免费跑通全流程，再补 `DASHSCOPE_*` 冲高质量，最后配 `CONSISTENT_IMAGE_URL` 或切 `kling-image` 顶格锁脸。
