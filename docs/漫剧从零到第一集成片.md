# 漫剧从零到第一集成片 · 可复制粘贴指令序列

> 用法：打开前端「聊天」页面，**按顺序把每一步的指令整段复制粘贴进去**，等 Agent 返回结果确认无误后，再进行下一步。
> 进度在左侧「漫剧」工作台随时可见；渲染/导出任务在底部「任务条」看进度。
>
> 开始前请先确认：`backend/.env` 已填 `DEEPSEEK_API_KEY`，服务已启动（`start.bat`）。

---

## 第 0 步 · 让 Agent 先自检（可选但推荐）

```
请先告诉我你现在能做哪些漫剧制作动作（tiktok_drama 的 action 列表），
并简述一条标准的竖屏短剧工作流。不要急着创建任何项目。
```

---

## 第 1 步 · 立项

把 `{slug}`、`{题目}`、`{一句话梗概}` 换成你自己的（slug 只用字母数字下划线）。

```
用 tiktok_drama 建一个漫剧项目，action=init：
- slug: my_drama_001（可改成你自己的，只能字母/数字/下划线/短横线）
- title: 《重生之逆袭千金》
- logline: 被赶出家门的豪门养女，重生回到三年前复仇翻盘。
要求：竖屏 9:16，目标每集 45 秒。建好后把项目路径和 project.json 关键内容回给我。
```

---

## 第 2 步 · 写人设 Bible（世界观 + 角色关系）

```
为这个项目写 bible 人设（action=save_bible），内容要包含：
1. 世界观与风格基调（建议古风/现代都市，选一个并说明理由）；
2. 2~4 个主角，每人一句口头禅和一个视觉锚点（例如红色发绳、戴金丝眼镜）；
3. 人物关系与核心冲突；
4. 前 3 秒钩子节奏、每集结尾留悬念的机制。
写好后回我 bible.md 的完整内容，让我确认。
```

---

## 第 3 步 · 建角色卡

```
基于 bible，为每个主要角色建角色卡（action=save_character），每人包含：
- name / look(详细外形描述，会进出图 prompt) / voice(配音音色) / colors / catchphrase / aliases
建好后回我角色列表。稍后我会在工作台上传并锁定每个角色的定妆参考图。
```

> ⚠️ **手动操作（工作台）**：进入「漫剧」→「角色」，为每个角色**上传定妆参考图并锁定**。这是全片一致性的根基，务必在出图前完成。

---

## 第 4 步 · 写系列大纲

```
写这个项目的系列大纲（action=save_outline），规划前 5 集：
每集一句话核心 + 钩子 + 反转 + 结尾悬念，保证追更欲。
写好后回我 outline.md 完整内容。
```

---

## 第 5 步 · 写第 1 集剧本

```
写第 1 集剧本（action=save_episode，episode=1，时长 45 秒），严格按下面结构：

# EP01 标题
- 时长: 45s
- 钩子: （前3秒必须有冲突/悬念/反差，禁止慢热）
- 悬念: （结尾留钩子）

## 分镜
### Shot 1 (0-3s)
- 画面:
- 对白:
- 字幕:
- 角色: 主角名

### Shot 2 (3-x s)
- 画面:
- 对白:
- 字幕:
- 角色: 角色名

（每个 Shot 都要标注时间段、画面、对白、字幕、角色；全片对白 80~150 字；
角色名必须用第 3 步的角色卡里的名字，保证出图吃外形、配音吃音色。）
写好后回我完整剧本文本。
```

---

## 第 6 步 · 解析分镜

```
用 parse_shots 解析第 1 集剧本（episode=1），生成 shots.json。
回我解析出的镜头数、每镜的 kind/size/speaker/时长，让我检查分镜表。
```

---

## 第 7 步 · 分类镜头

```
用 classify_shots 对第 1 集所有镜头分类（episode=1）：
按对白推断每个镜头的 kind/speaker（定场=establishing、对白=dialogue、动作=action 等）。
回我分类结果，不要覆盖我已锁 kind 的镜头。
```

---

## 第 8 步 · 出画面（候选墙）

```
对第 1 集的关键镜头逐个 generate_candidates（每镜出 4 张候选），
先只做 Shot 1~3，给我候选图预览链接。
我想在工作台逐张点选锁定画面（换图不重配音）。
```

> ⚠️ **手动操作（工作台）**：进入分镜页，在候选墙**点选最满意的一张锁定**；不满意的可再重抽或手传覆盖。

---

## 第 9 步 · 配音（逐句核对后生成）

```
第 1 集每个 Shot 的对白，按各自「角色」卡绑定的音色生成配音（TTS）。
生成前先把每一句的（角色 / 音色 / 文本 / 时长）列给我确认，再落盘。
```

---

## 第 10 步 · 先 QC 验收

```
在导出前跑 qc_episode（episode=1）整集验收：
身份一致性 / 口型 / 闪烁 / 响度 四项。
注意：skipped 不得记为通过；响度不达标只能重混音（mix）不能整集重渲。
把 verdict、各项分数、待修镜头列表回给我。
```

---

## 第 11 步 · 时间线 + 导出

```
第 1 集验收通过后，帮我在时间线页确认：
- 镜序正确；- 每个切点/转场合理；- 音量合适；- BGM 已选且 license 可用。
然后 export_timeline 导出成片，回我 play_url（预览链接）。
```

---

## 第 12 步 · 回看与打磨

```
用 get 回看第 1 集进度，告诉我：
- 成片视频路径/预览链接；
- 还有哪些镜头是 dirty（未渲/待重修）；
- 哪些镜头已锁定。
我接下来会对不满意的地方用 rerender_shot 单镜重做（只重做指定层）。
```

---

## 一键懒人版（让 Agent 自动连续执行）

> 想快速跑通流程时用这段；但**专业成品建议走上面的分步版**，每步人工把关。

```
请为我的漫剧项目完成从立项到第 1 集成片的完整流程，题材用「重生复仇」：
建项目(init) → 写bible → 建角色卡 → 写大纲 → 写第1集剧本 → parse_shots →
classify_shots → 出画面候选 → 配音 → QC验收 → 时间线导出。
每完成一步都简要回我结果和下一步；遇到需要我决定的点（角色外形、候选图、
BGM license、验收结论）先停下来问我。
渲染/导出前严格遵守 check：先 classify、看预算、锁画面再开口型、
导出前先 qc 且 skipped 不当通过。
```

---

## 常见补救指令（随时可用）

| 情况 | 指令 |
|------|------|
| 某一镜画面不顺眼 | `用 rerender_shot 重做第1集 Shot N 的 scene 层（只重出画面，不重配音）` |
| 改了一句台词 | `用 rerender_shot 改第1集 Shot N 的对白，layers=voice,overlay（只重配音+字幕）` |
| 想锁死某一镜 | `用 lock_shot 锁住第1集 Shot N 的 shot（整镜）` |
| 只重渲脏镜 | `用 rerender_dirty 重渲第1集所有脏镜` |
| 换背景音乐 | `用 mix_episode 换第1集 BGM，license_ok=true` |
| 查后台任务进度 | `用 poll_job 查 job_id=xxx 的进度` |
| 给动作镜头加运动 | `对第1集 Shot N 用 generate_i2v 试 I2V 运动` |
| 给对话特写开口型 | `对第1集 Shot N 用 generate_lip 生成口型（需有 speaker）` |

---

## 关键提醒

1. **前 3 秒钩子**决定留存，剧本阶段就要卡死。
2. **定妆参考图必须先锁**，否则角色会崩脸。
3. **渲前看预算、锁画面再开口型、导出前先 QC**，Agent 的 check 卡点会强制提醒，别跳过。
4. 当前默认 `balanced` 预设走的是**免费 flux + mock 口型/I2V + edge-tts**，先跑通全流程；要冲商用再切换 `pro` 并配置真实模型（即梦/可灵/MuseTalk/火山高拟真）。
